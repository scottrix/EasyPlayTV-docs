Two-sentence summary

EasyPlayTV is a Kodi video addon that aggregates free-to-air UK streaming catch-up services — BBC iPlayer, ITVX, My5, Channel 4, STV, Blaze — plus a couple of live channels (Sky News). It does two jobs:

  1. Live TV grid — exposes the live-channel resolvers (BBC, Sky News, C4, ITVX, STV, Blaze) behind a single plugin:// browse UI.
  2. Populate the Kodi library — a background service syncs the provider catalogues into Kodi's central MariaDB video database as if they were on-disk files, using plugin:// URLs as virtual filenames so the rows behave like any other Kodi library entry. The user then browses Movies and TV Shows through Kodi's own library views; the addon never serves the catalogue.

Project layout

EasyPlayTV/
├── addon.xml                 — Kodi addon manifest
├── default.py                — plugin entry point (cached per-call routing)
├── service.py                — long-lived Kodi Monitor daemon (scheduled syncs)
├── README.md
└── resources/
    ├── settings.xml          — addon settings UI (db_source, max_resolution, itvx creds, …)
    ├── language/en_gb/strings.po
    └── lib/
        ├── __init__.py        — shared helpers: provider_map, setup_dash_item, get_ua, …
        ├── genres.py          — PROVIDER_LABELS lookup
        ├── library_sync.py    — sync engine (1.7k LOC — heart of the addon)
        ├── strm.py            — URL builders (_build_*_strm_url) + show fetcher for sync
        ├── catalog_check.py   — small stale-title marker (marks DB rows whose source has gone)
        │
        ├── bbc.py / bbc_vod.py     — BBC iPlayer live + VOD
        ├── itvx.py / itvx_vod.py   — ITVX live + VOD (OAuth/JWT session)
        ├── c4.py / c4_vod.py       — Channel 4 live + VOD (AES-CBC token decrypt + Widevine)
        ├── my5.py / my5_vod.py     — My5 VOD (Cassie HMAC/AES keys extracted from live JS)
        ├── stv.py / stv_vod.py     — STV live + VOD
        ├── blaze.py / blaze_vod.py — Blaze TV (HTML scraping)
        └── sky.py                  — Sky News live (Brightcove)
