EasyPlayTV

A Kodi video add-on providing UK live TV channels and on-demand content from BBC iPlayer, ITVX, Channel 4, My5, Sky News, STV Player, and Blaze — all self-contained with no external plugin dependencies.

Download EasyPlayTV

Free and open source. Requires Kodi 19+ (Matrix or later) with inputstream.adaptive.

Quick start

  1. Download the ZIP file above
  2. Open Kodi → Add-ons → Install from ZIP file → select the downloaded file
  3. See Installation for full instructions including MySQL setup

Features

  • 28+ live TV channels — BBC, ITV, Channel 4, Channel 5, Sky News, STV, Blaze
  • Movies & TV Shows library — synced to Kodi's library with TMDb metadata (posters, fanart, plots, ratings)
  • Provider badges — [BBC], [ITVX], [C4], [My5], [STV], [BLAZE] on all titles
  • Background sync — each provider syncs every 6 hours automatically
  • Optional sign-in — ITVX, Channel 4, and My5 account login for premium content

For developers

EasyPlayTV is two cooperating processes inside Kodi:

  1. Plugin — default.py, invoked on every listitem click. Short-lived, stateless: routes URLs to per-provider resolvers.
  2. Service — service.py, a long-lived xbmc.Monitor daemon that syncs provider catalogues into the Kodi MySQL database every 6 hours.
